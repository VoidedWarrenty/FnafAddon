# Lessons Learned

Living record of assumption failures and the adaptations they forced.

Unlike Rejected Patterns (which describe *a technique that doesn't
work*), Lessons Learned describe *what we believed, what actually
happened, and how our mental model changed.*

Each entry follows:

- **What we expected** — the mental model going in
- **What actually happened** — the observed behavior
- **Why the assumption was wrong** — the corrected mental model
- **How we adapted** — the durable change (usually a doc, an ADR, or a
  process rule)

These are institutional knowledge. Future engineers should read the
Lessons Learned index before starting adjacent work.
